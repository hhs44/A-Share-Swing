# A股波段研究：V1 工程实现（数据验收未完成）

**模拟研究，不构成投资建议。** 不含券商接入、实盘账户或自动下单。当前不能宣称已通过 V1 全部验收：真实历史数据缺失，远端行情接口访问失败，未产生真实回测成绩。合成测试只能证明程序行为。

## 安装和命令

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q
python -m ashare_swing scan --demo --asof 2026-11-04
# 最新完整交易日扫描（一条命令；必须事先提供已授权、校验过的数据包）
python -m ashare_swing scan --bundle data/history --output reports/staged
# 可选 --asof 只能是最新完整交易日，不允许将旧数据当作当日数据。
python -m ashare_swing publish --staged reports/staged --output reports/published
# 2020–2023研究、2024–2025样本外、2026截至实际完整交易日，分别独立以1万元起算
python -m ashare_swing backtest --bundle data/history --end YYYY-MM-DD --output reports/backtest.json
```

`YYYY-MM-DD` 必须替换为实际已完成的交易日。研究分期由 CLI 固定，不做参数寻优；`--start` 可缩小区间，不能把缩短区间的结果视为完整六年回测。缺失文件/数据校验失败返回非零退出码；回测失败写入 `valid:false, metrics:null`。没有数据时不运行演示数据替代真实回测。

演示文件以 `-DEMO` 区分，数据库为 `signals-DEMO.db`，不污染正式信号。真实日报写 Markdown/JSON，数据库 `(code, signal_date)` 幂等覆盖，后续1/5/10/15交易日收盘表现写 `outcome`（不是可成交收益）。发布仅北京时间19:00后接受当天、摘要匹配的报告。无满足条件的股票时展示不足原因，不凑足3–5只。

## 历史数据契约

入口为本地目录中的四个 CSV 与 `manifest.json`。不能仅下载今天的股票名单再回溯。须由有权限的数据供应方提供**含退市证券的逐日历史全股票池、历史名称/类别/IPO日期/ST状态、停牌状态、当日权威涨跌停价、公司行动审计和双指数**。本仓库尚未实现此数据供应链。AKShare 原始日线自身不满足这些要求，因此原先仅传 `--symbols` 的真实扫描现在明确拒绝执行。

| 文件 | 字段/要求 |
|---|---|
| calendar.csv | `date`，交易所实际交易日，升序不重复，覆盖预热和研究区间 |
| bars.csv | `code,date,open,high,low,close,volume,amount`；原始未复权价格，volume统一为**股**（AKShare日线常为手，导入须转换），amount为元；停牌也须显式携带估值行情 |
| status.csv | `code,date,name,board,ipo_date,listed,st,delisted,suspended,limit_up,limit_down,action_factor`；每天对历史全股票池显式给出状态，布尔用0/1；board为main/chinext/star，暂不支持北交所/ETF；价格为交易所当日实际限制，禁止按现在规则回填 |
| indices.csv | 同bars字段，code为 `sh000300`（沪深300）和 `sz399001`（深证成指）；连续历史数据，指数成交量不用于筛选 |

`manifest.json` 格式（示意，不能照抄为真实数据证明）：

```json
{
  "source": "供应方及版本/快照ID",
  "license": "授权范围及许可引用",
  "retrieved_at": "2026-11-04T16:40:00+08:00",
  "calendar_through": "2026-12-31",
  "point_in_time_universe": true,
  "includes_delisted": true,
  "corporate_actions_verified": true,
  "sha256": {
    "calendar.csv": "文件原始字节的SHA256",
    "bars.csv": "文件原始字节的SHA256",
    "status.csv": "文件原始字节的SHA256",
    "indices.csv": "文件原始字节的SHA256"
  }
}
```

这些声明和哈希用于审计与防意外修改，**不是独立的供应方真实性验证**。数据负责人必须核实来源和覆盖完整性。`calendar_through`是日历覆盖日期，不能把它作为额外交易日。日报拒绝过期采集时间和未来采集时间；北京时间16:30前只选上一个完整交易日。

目前凡 `action_factor != 1` 均拒绝整包回测：尚未完成现金分红、拆股、配股和退市现金处置。不得为了通过检查删掉公司行动或把因子填1。含除权的2020–2026全市场包会被拒绝，这是明确的未实现项；不存在合法的完整真实绩效报告。证券持仓一旦缺少状态/行情也拒绝继续，不能偷偷删除持仓。

## 策略、执行与费用

收盘价>MA20>MA60，突破前20日最高**收盘**价（不含当日），相对前5日均量1.2–2.5倍，20日收益跑赢沪深300，距MA20不超过8%，当日涨幅不超过5%，20日均成交额>1亿元。价格8–20元是排序偏好。双指数均收盘>MA20>MA60才允许新仓。评分为规则通过数加价格偏好；没有公告或财务因子。

事件引擎以T收盘生成信号、T+1开盘或以后成交；未成交买单当日失效，下次必须重新发信号。买入100股整数倍；卖出不得早于买入后下一交易日。持有5日后收盘跌破MA20可在次日退出，最长15个交易日发起退出，止损/停机可提前退出，跌停/停牌可延后。单日触及涨停则保守拒绝买入，触及跌停则拒绝卖出。单笔成交不得超过当日成交股数1%，滑点单边0.1%，不能超出日内价格区间；跳空止损以较差的开盘价成交。日线无法还原真实成交队列；日成交量限制是事后可用的保守容量假设，不代表开盘可得流动性。

默认股票佣金万分之三、每边最低5元；2020年以来卖出印花税：2023-08-28以前千分之一，此后万分之五；双边过户费：2022-04-29以前十万分之二，此后十万分之一。佣金假设为已含经手/监管费用的全佣，不重复叠加。实际券商费率不同须修改配置。仓位计划按上述区间最高税费保守预留；成交账本按当日费率计算。仅支持沪深A股，禁止用于其他品种。

全账户初始1万元，现金至少4000元，总仓位预算6000元，最多两只，单只目标1500元/硬上限2000元，计划损失（含往返费用和滑点）不超过100元。当前目标作为保守资金上限，不能买一手则拒绝。限制针对下单时，市价上涨可使持仓市值超过初始额度；不自动强行再平衡。跳空实际亏损可能超过计划风险。

回撤8%预警、12%冻结新仓、15%停机审查，回测内15%状态锁存到结束并尝试退出持仓。每日建议目前是**每天独立空仓模拟计划**，不是持续模拟账户，不接收真实账户资产；持续组合资金控制仅在回测中实现。回测末尾持仓按收盘盯市，不假装已平仓。报告含总收益、按自然日年化、最大回撤、已完成交易数/逐笔净盈亏/胜率、同区间沪深300价格收益对照、成交/拒单账本、现金和未平仓状态。分期账户重置；基准为同期首日至末日收盘价格收益，不含股息，策略则从首日前空仓开始，需考虑比较口径。

## 自动日报与CI

`.github/workflows/daily.yml`：北京时间工作日16:30扫描、17:00重试、19:00重新校验扫描并发布；支持workflow_dispatch手动重试；GitHub定时任务可能延迟。真实交易日历判定节假日。文件不存在、日历过期、数据未更新则作业失败，禁止上传当日错误报告。产物通过Actions artifact供审阅，不推送邮件或交易指令。

需要维护者配置 `ASHARE_BUNDLE_PATH`（默认 `data/history`）并让runner取得有授权的更新数据。**当前工作流没有数据采集/授权供应方下载步骤，因此默认会因缺少数据失败；尚不能无人值守生成真实日报。** 不要把商业行情/凭据提交公开仓库。SQLite用Actions cache跨运行尽力恢复，完整历史应由部署方使用持久卷或数据库保存；缓存可被清除，不能当作可靠长期存储。失败重试不重复信号主键；不保证跨文件/数据库事务原子性，多进程并行CLI应由外部锁保护；工作流已串行化。

CI运行离线pytest和演示扫描；不把合成回测当作真实绩效。测试结果、接口失败证据和验收缺口见 [TEST_RESULTS.md](TEST_RESULTS.md)。

## 数据权限与剩余验收

AKShare及上游接口可变，开源库许可不等于上游行情的再分发/商业使用许可。须核实交易所、指数和供应方授权、保存方式及再分发限制。运行依赖已安装AKShare 1.20.25，接口符号存在，但本环境访问新浪/上交所/东方财富失败，尚未验证最新行情时间戳、股票名称及交易日历内容。
