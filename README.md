# A股短中线选股研究系统（MVP 0.1）

> **研究用途，非投资建议。** 本仓库不连接券商、不含自动下单；演示数据是合成数据，不能用于选股。研究程序还未通过实盘级回测和数据接口环境验证。

## 目标
本金￥10,000；短中线波段研究；阶段最大容忍回撤20%，但12%提前冻结新开仓、15%停机审查；最大两只个股，股票按100股整数倍。固定趋势突破规则：

- 收盘价>MA20>MA60；突破前20个交易日最高收盘价（不含当日）。
- 相对前5日均量放大1.2~2.5倍；20日涨幅跑赢沪深300；收盘价不高于MA20的108%；当日涨幅<=5%。
- 20日平均成交额 > 1亿元；研究价格优先8~20元。

**注意：** 第一版还没有完成全部ST、停复牌、上市时间、公司公告、实时涨跌停及复权完整性检查，不能直接把候选结果视为可交易清单。对主板和创业板等交易制度差异必须做交易所规则检查。`scan`默认股票代码只是演示样本，不代表推荐。

## 运行

```bash
python3.11 -m venv .venv
source .venv/bin/activate   # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
pytest -q
python -m ashare_swing scan --demo --asof 2026-11-04
```

演示命令用合成K线验证流程。**真实行情只在确认最后完整交易日以后使用**，例如：

```bash
python -m ashare_swing scan --symbols 000001,600000 --asof YYYY-MM-DD
```

若远端接口为空、数据未更新、指数时间错配，程序应报错而不是伪造结果。报告输出 `reports/YYYY-MM-DD.md`，研究记录保存 `data/signals.db`。

## 当前交付与局限

已实现：AKShare 个股及沪深300适配层、数据缓存、严格按信号日期截断数据、趋势突破筛选、100股风控模拟、SQLite存储、Markdown日报、离线单元测试、CI。

未实现（需交给Codex Cloud续建）：
1. 2020年至2026年的**真实历史回测**（Backtrader、T日信号T+1开盘成交、佣金最低收费、税费历史分段、滑点、T+1、停复牌、涨跌停不可成交、上市时点和退市偏差）；
2. 交易所信息、ST、历史IPO日期、公告及财报发布时间的可靠数据链；
3. 历史成分股和企业行动数据的 point-in-time 校验；
4. ETF和指数市场状态阈值、双标的投资组合层面的回撤控制与模拟成交；
5. 定时调度（16:30扫描、19:00日报）和通知渠道、失败重试、交易日历；
6. GPT基于真实公告的有据可查的说明（可选）。

### 不要把最初回测当作真实绩效
当前可从AKShare获取不复权日线进行数据读取，但拆分除权等公司行动会影响跨期收益；回测需 point-in-time 复权和历史样本名单，否则回测收益无效。绝对不要展示未经运行的历史收益率。`--demo`只用虚构数据做冒烟测试。
